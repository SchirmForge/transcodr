# Encoding Rules

Profiles and Watch Folders are the two building blocks for automated encoding:

- **Profiles** define how media is encoded (codec, quality, container, and related options).
- **Watch Folders** define where jobs come from and how they are submitted automatically.

This page is a quick overview only.

## Where To Go Next

- For profile details, open **Encoding Rules > Profiles**.
- For watch folder details, open **Encoding Rules > Watch Folders**.

## UI Scope

Create, edit, and duplicate actions in the UI are planned for a future release.  
Today, these pages focus on viewing and managing current configuration/state.
